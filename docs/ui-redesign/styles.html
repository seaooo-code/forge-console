推进

以模块为中心，把构建从测试一站一站推进到生产。每次推进前先看清这次带上了哪些提交。

分区方式
三个环境是并排的浅灰站台，推进面板浮在上层
发布怎么做
点站台之间的箭头 → 看提交差异 → 选全量或灰度
信息密度与主题
中等，蓝色只给推进方向和主按钮；支持浅色和深色
最适合

动态

首页是一条按时间排列的动态，需要你处理的事置顶。构建成功后直接在动态里展开发布，不用跳页。

分区方式
每条动态是悬停才显出的浅灰块，需要处理的常驻浅灰底
发布怎么做
在构建成功的动态上点发布 → 原地展开 → 确认
信息密度与主题
中低，紫色只给主操作和发布；支持浅色和深色
最适合
多人协作、需要知道谁刚做了什么
